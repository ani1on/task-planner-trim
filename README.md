# Task Planner Trim

Урезанная версия Task Planner: десктопный клиент на PySide6, REST API на FastAPI
и PostgreSQL.

## Оставленные функции

### Клиент

- Регистрация, вход, выход и восстановление пароля.
- Дашборд со статистикой задач и прогрессом проектов.
- Задачи: создание, редактирование, удаление, статусы, приоритеты, дедлайны и
  назначение участникам.
- Фильтр задач по проекту и параметрам задачи; текстовый поиск по задачам.
- Канбан-доска со сменой статуса.
- Проекты с редактированием и поиском; управление участниками и ролями.
- Комментарии к задачам.
- Настройки профиля и светлой/тёмной темы.
- Обновление данных в реальном времени через WebSocket.

### Сервер

- Аутентификация, профиль и пользовательская настройка темы.
- Проекты, участники и роли доступа.
- Задачи и комментарии.
- Заметки через API (клиентского экрана заметок нет).
- Журнал активности и дашборд.
- Поиск по задачам, проектам и заметкам.
- WebSocket-события задач, комментариев, проектов и участников.

Прочие функции исходного приложения (календарь, повторения, подзадачи, теги,
чек-листы, напоминания, уведомления и журнал активности в интерфейсе) удалены.
История миграций Alembic сохранена без переписывания.

## Запуск

1. Создайте и активируйте виртуальное окружение, установите проект:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -e ".[dev]"
   ```

2. Скопируйте `.env.example` в `.env` и задайте секретный `JWT_SECRET_KEY`.
   Docker Compose создаёт отдельную базу `task_planner_trim` на порту `5433`,
   не используя базу исходного проекта:

   ```powershell
   docker compose up -d postgres
   ```

3. Примените миграции и запустите API:

   ```powershell
   alembic upgrade head
   uvicorn server.main:app --reload
   ```

4. Запустите клиент из корня проекта:

   ```powershell
   python -m client.main
   ```

   По умолчанию клиент подключается к размещённому API. Для локального сервера
   задайте адрес перед запуском:

   ```powershell
   $env:TASK_PLANNER_API_URL = "http://localhost:8000"
   python -m client.main
   ```

### Сборка клиента для Windows

Установите зависимости разработки, затем соберите автономный `.exe` из корня
проекта:

```powershell
pip install -e ".[dev]"
python -m PyInstaller --noconfirm --clean --onefile --windowed --name TaskPlanner --add-data "client\themes\light.qss;client\themes" --add-data "client\themes\dark.qss;client\themes" client\main.py
```

Файл `dist\TaskPlanner.exe` будет подключаться к API по умолчанию. Переменная
`TASK_PLANNER_API_URL`, если задана на компьютере пользователя, переопределит
этот адрес.
